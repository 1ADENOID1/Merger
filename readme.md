Для сборки проекта запустить build.bat
Для зпуска утилиты запустить start.bat
Внимание: Для работы утилиты файл start.bat необходимо в нём задать следующие значения:

DISTR_DIR - Абсолютнй путь к директории с конфигурацией дистрибутива (в дистрибутиве это директория resources, содержащая json файлы)
USER_DIR - Абсолютнй путь к директории с пользовательской конфигурацией
BACKUP_DIR - Абсолютнй путь к директории, в которую будет производиться бекап пользовательских файлов перед началом работы утилиты
CREATE_BACKUP_SUBDIR - Режим бекапа: true - создать поддиректорию backupN (где N - номер папки, если она дублируется) в BACKUP_DIR и выполнить бекап в неё, 
                                     false - не создавать поддиректорию, бекап будет выполнен в BACKUP_DIR. 
									 Внимание: для режимма false обязательно, чтобы BACKUP_DIR была пустой
FILE_ENCODING - Кодировка файлов. По умолчанию UTF-8 (является стандартом для json)
